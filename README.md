## 👨‍💻 A little about me

I'm a full-stack developer based in Egypt, working across **React, Next.js, TypeScript, Node.js, Express, and MongoDB**. I enjoy taking a product from its first screen through its data model, API, and deployment.

**UI design and animation are the parts of frontend development I enjoy most.** I like refining layouts, interactions, and the small details that make an interface feel natural. That same attention carries into my backend work: clear boundaries, input validation, and permissions that match how the product is used.

- **Product development:** dashboards, learning platforms, content management systems, and business workflows.
- **Interface craft:** responsive layouts, Framer Motion, reusable components, and light/dark themes.
- **Bilingual experiences:** Arabic/English interfaces with RTL/LTR layouts and localization.
- **Backend engineering:** REST APIs, authentication, role-based access, payment integrations, and media handling.
- **Continuous learning:** C++ problem-solving, data structures, algorithms, and software architecture.

- Arabic/English UI, RTL/LTR layouts, light/dark themes, and reduced-motion support.
- Client portals, proposal acceptance, task boards, and invoice/payment tracking.
- A scoped work assistant with optional Gemini/OpenAI integration.
- Modular API architecture, workspace isolation, and automated browser checks.

**Next.js · TypeScript · React · Express · MongoDB · Playwright**

## ✨ How I approach the work

- **Start with the user journey.** Connect the interface, permissions, and data around an actual task.
- **Care about the details.** Make layouts, feedback states, keyboard interactions, and motion part of the experience.
- **Build for the next change.** Keep components reusable and separate business rules from delivery and storage.
- **Keep improving.** Use testing, feedback, and iteration to refine both the product and the code.
